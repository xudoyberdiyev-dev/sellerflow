Lucide icon glyph tinted by currentColor; use for every icon in SellerFlow Admin.
```jsx
<Icon name="lock" size={16} />
<Icon name="shield-check" size={20} label="Himoyalangan" />
```
- `name`: kebab-case Lucide name. Decorative by default (aria-hidden); pass `label` when the icon alone carries meaning.
- Sizes: 12 (badges), 14 (sm buttons), 16 (default), 18–20 (modal/empty chips).
